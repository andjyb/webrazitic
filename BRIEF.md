## Exigences techniques
- Site statique en HTML, CSS et JavaScript léger, sans framework lourd ni
  étape de build, pour que je puisse le modifier facilement.
- Responsive, avec un rendu irréprochable sur mobile.
- Rapide et accessible : images optimisées, contrastes suffisants, balises
  sémantiques.
- SEO de base : balises title et meta description par page, Open Graph,
  sitemap.xml, robots.txt, données structurées schema.org de type
  ProfessionalService.
- Toutes les informations modifiables (prix, email, nom, textes des offres)
  regroupées au même endroit ou clairement repérables.
- Prêt à déployer gratuitement sur Netlify, Cloudflare Pages ou GitHub Pages.

## Style
- Sobre, moderne, inspirant confiance : une couleur principale (bleu ou vert

- Ton chaleureux et simple, sans jargon technique : mes clients ne sont pas
  informaticiens. Vouvoiement.
- Pas d'images de stock génériques : utilise des icônes SVG simples et des
  illustrations légères.
